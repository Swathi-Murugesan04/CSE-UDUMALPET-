# CSE Computer Education — Premium Glow V5

A responsive single-page website for CSE Computer Education, Udumalpet, using a cinematic charcoal, black and warm-gold visual theme.

## Deploy on GitHub Pages
1. Extract the ZIP.
2. Upload `index.html`, `styles.css`, `script.js`, `favicon.svg`, and the `assets` folder to the repository root.
3. In GitHub, open **Settings → Pages** and select the main branch and root folder.
4. After publishing, refresh the page. If an old version remains cached, perform a hard refresh.

## Website features
- Responsive navigation and course categories.
- Course cards that filter by Computer Applications, Programming & Data, and Career Skills.
- Course links preselect the related enquiry option.
- Enquiry form prepares a WhatsApp message for the user to review and send. It does not store submissions.
- FAQ accordions and Google Maps directions.
- Six optimized local WebP visual assets with a consistent black-and-gold art direction.
- Motion-reduction preference support.

## Before publishing
Verify the phone/WhatsApp number and address with the institute. Course availability, fees, schedules, certificates and testimonials are intentionally not presented as confirmed facts unless verified.
